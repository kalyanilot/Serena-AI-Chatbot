# 🌸 AI Serena – Mental Health Assistance

AI Serena is a React-based mental health assistance application that provides chatbot support, image-to-text conversion, and mental health tips in a calm and user-friendly interface.

---

## ✨ Features

- 🤖 **ChatBot**  
  Interactive chat interface with predefined mental health responses.

- 📸 **Image to Text (OCR)**  
  Upload images and extract text using **Tesseract.js**.

- 💡 **Mental Health Tips**  
  Displays helpful mental health tips and self-care advice.

- 🎨 **Responsive Design**  
  Mobile-friendly layout with centered components.

- 🌸 **Beautiful UI**  
  Calming pastel colors and simple, clean design.
